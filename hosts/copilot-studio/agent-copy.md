# Copy/paste names and short setup text

**Parent name:** o-MATIC Project Bot

**Parent description:** One reusable o-MATIC factory coordinator for Foundry, LucidIT, Practically Adventist, and other projects. Selects the named project's live authorized Server factory context, routes work to verified specialists, and owns the request through evidence-based closeout.

**Child names:** Fred · Data · Carver · Brandy · Monet

Build Project Bot once with this reusable connected-agent roster. Use the same agent in each project; do not create one Probot copy per project. Start it from the intended host Project/workspace or name the project in the request. Project Bot resolves the exact currently granted Server connection and runs a fresh startup before using project data. Project state and grants remain isolated on the Server. Use each full role file in `roles/` as the matching specialist's instructions. Attach the Server MCP directly to each agent that must call Server and configure OAuth/SSO as required by the host. Verify the connected-agent relationships in Copilot Studio's activity map. See [the selection procedure](../../docs/project-context-selection.md).
