# Claude Code marketplace

The repository root contains a Claude Code marketplace catalog pointing to this plugin. From Claude Code, add `LucidIT-LLC/o-matic-project-bot` as a marketplace, then install `omatic-project-bot@o-matic-project-bot-marketplace`.

The plugin contains reusable specialist definitions and a Server MCP connector. Build a host-native Factory Agent composition with the intended lead and roster. Validate Cowork and Claude Code separately. Agent components are not assumed available in general Claude chat. Connector setup and OAuth/SSO sign-in remain separate from plugin installation.
