# OpenAI plugin projection

This package provides specialist skills and a remote Server MCP configuration. It is not a guarantee that all ChatGPT or Codex surfaces provide native multi-agent handoffs. Bind the same Server MCP to the coordinator; bind specialists only when required and supported. Confirm OAuth during installation. For OpenAI public directory submission, complete current portal metadata, reviewer tests, identity checks, security review, and license review. The placeholder test cases in `plugin.json` are intentionally not a submission-ready review suite.
