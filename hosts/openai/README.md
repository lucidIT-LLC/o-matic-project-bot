# OpenAI plugin package

This folder is a portable Agent Plugins package: `plugin.json`, `mcp.json`, and `skills/` are all at the package root. It is the plugin distribution; installing it does not create a ChatGPT Workspace Agent or publish an entry in the Agents directory. For that, use [`../chatgpt-workspace-agent/BUILD.md`](../chatgpt-workspace-agent/BUILD.md). It provides specialist skills and a remote Server MCP configuration; it does not guarantee that every ChatGPT or Codex surface provides native multi-agent handoffs. Configure the host-native composition separately. Confirm OAuth during installation. For OpenAI public directory submission, complete current portal metadata, reviewer tests, identity checks, security review, and license review. Directory review and publication are separate from this GitHub repository.
