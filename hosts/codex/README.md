# Codex projection

The root `AGENTS.md` is the Probot/Project Bot lead contract. The plugin package provides role skills and the o-MATIC Server MCP declaration. This adapter also includes native project-scoped Codex specialist subagents in `.codex/agents/`; copy that folder into the project root when configuring a project. Codex subagents inherit the parent session permissions, provider, and MCP servers. That differs from some other host surfaces; inspect the active tool set and still verify Server identity/grants.

The native agent files define real Codex subagent roles when multi-agent tools are enabled. ChatGPT plugin installation alone does not install those project-scoped agent files or prove delegation.
